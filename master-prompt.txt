## Master Prompt

Build a full-stack web application following the exact architecture, design system, and code conventions below. These patterns are domain-agnostic — whether the app is for inventory, HR, CRM, billing, or anything else, apply them consistently.

---

### 1. Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite 5 (`@vitejs/plugin-react`) |
| Routing | `react-router-dom` v6 |
| HTTP client | `axios` with interceptors for auth token & 401 redirect |
| Notifications | `react-hot-toast` (top-right, 3s, dark style) |
| Styling | Tailwind CSS via PostCSS — utility classes only, no CSS modules/styled-components |
| Backend | Node.js + Express |
| Database | MongoDB via Mongoose |
| Auth | JWT (`jsonwebtoken`), Bearer token in `localStorage` |
| Validation | `express-validator` on backend; custom validation utils on frontend |
| Language | JavaScript (`.js` backend, `.jsx` frontend) |

### 3. Design System

**Colors — muted gray palette. No bright blues:**
- Primary: `bg-gray-800`, `bg-gray-600` (active nav)
- Text: `text-gray-900` (headings), `text-gray-500/400` (muted), `text-gray-700` (body)
- Borders: `border-gray-100/200/300`
- Focus ring: `focus:ring-gray-400`
- Background: `bg-gray-50` (page), `bg-white` (cards)
- Danger: `bg-red-600 text-white`, `text-red-600`, `hover:text-red-600 hover:bg-red-50`
- Edit icon: `text-gray-400 hover:text-blue-600 hover:bg-blue-50`
- Links: `text-gray-500 hover:text-gray-700 hover:underline`

**Reusable component patterns:**
```html
<!-- Card -->

<!-- Page heading -->
```

### 4. CRUD Page Pattern (every entity list page)

Each entity's list page follows this exact structure:

```
State: [items], [loading], [showForm], [editing], [form], [errors], [submitting], [deleteTarget], [searchTerm]
  + [referenceData] if entity has foreign-key references

fetchItems — useCallback, useEffect on mount

Table columns: [{ key, label, sortable?, render? }]
+ actions column with edit (blue hover) / delete (red hover) buttons

Form: overlay modal, grid-cols-1 sm:grid-cols-2 gap-4
  label * for required fields
  validation: iterate fields array, collect errors
  submit: validate → setSubmitting → API call → toast → reset → refetch

Delete: Modal confirm → API delete → toast → close → refetch

Search: client-side .toLowerCase().includes(term)

Edit: openEdit sets editing + fills form from row data
```

### 5. Backend API Pattern

- **Controllers:** `{ create, getAll, getOne, update, delete }` — all `async (req, res, next)` with try/catch → `next(error)`
- **Duplicates:** explicit `findOne` checks before create/update
- **Delete protection:** check for child records before deleting
- **Validation:** `express-validator` chains + `handleValidationErrors` middleware
- **Auth route pattern:** `router.post('/', auth, validation, controller.method)`
- **Response envelope:** `{ success: boolean, message: string, data?: any }`
- **Auth response:** `{ token, user: { id, fullName, username } }`
- **Recovery token:** `crypto.randomBytes(4).toString('hex').toUpperCase()`, stored on User, returned on register, validated on forgot-password

---

### 6. Auth & Routing Flow

- AuthContext manages `{ user, token, loading, login, register, logout, isAuthenticated }`
- `ProtectedRoute` = `loading → Loading` | `!isAuthenticated → Navigate /login` | `<Layout><Page /></Layout>`
- `PublicRoute` = `loading → Loading` | `isAuthenticated → Navigate /dashboard` | `<Page />`
- Axios interceptor: attaches Bearer token, on 401 clears auth + redirects to `/login`
- Toaster rendered once in App, no toast calls in individual pages beyond `toast.success / toast.error`

---

### 7. Consistency Rules (non-negotiable)

- `import React from 'react'` at top of every `.jsx` file
- No comments in production code
- No emojis in code or UI unless explicitly requested
- Every form field has `<label>` with `*` for required
- Error text: `className="mt-1 text-xs text-red-500"`
- All API responses: `{ success: boolean, message: string, data?: any }`
- Colors stay muted grays — `bg-gray-800` for primary, `#374151` as brand primary
- Currency / monetary values: prefix with `RWF ` (or adapt per domain), use `Number(val).toLocaleString()`
- Total price / computed columns rendered in table as `col.render`
- CSV export: build rows array, join with commas, create Blob + download link
- Reports: tab bar with date controls inline on the same row, report title below, summary cards, then transaction/record table
- Sidebar: `navItems[]` array with `{ label, path, icon }`, NavLink with `isActive` styling
